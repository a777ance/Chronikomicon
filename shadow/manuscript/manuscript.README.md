# Manuscript

The novel itself — chapters, metadata, styling.

**What goes here:**
- Chapter files
- Book metadata (for Pandoc)
- Typography and style definitions

**File/Folder Naming:**
- Active chapters: `NN-title.md` — e.g. `01-the-first-hour.md`. Two-digit number, then a
  slug. (This is the portfolio-wide form, matching the root README and the verification
  checklist in `access/CLAUDE.md`; the older bare `chapter-XX.md` is superseded.)
- Other active files: `styles.css`, `metadata.yaml`, etc.
- Archived files: `[01-the-first-hour].md`, `[old-draft].md`
- Subfolders follow the same pattern: `Scenes/` (active) or `[Scenes]/` (archived)

**How to manage:**
1. Active chapters live as `NN-title.md`
2. Old versions become `[NN-title].md` (add brackets)
3. Read `manuscript.README.md` (this file) for structure
4. Rename files by adding/removing brackets to toggle state

**Metadata and Styles:**
These live in their working folders. Reference as needed, bracket if archiving versions.
