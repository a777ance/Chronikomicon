# Mindmap

The worldbuilding incubator — loose, hyperlinked, generative.

**What goes here:**
- Character landscapes
- Thematic explorations
- Scene seeds and narrative ideas
- World details and brainstorms
- The Twelve-Hour Clock (applied)

**File/Folder Naming:**
- Active ideas: `characters.md`, `Judas/`, `themes.md`
- Archived/exploring: `[Judas-old].md`, `[Judas]/`, `[abandoned-scenes]/`
- Brackets = not actively being used, but keeping for brainstorm reference

**Structure:**
- Files use breadcrumb naming: `mindmap.md`, `characters.md`, `[old-concept].md`
- Subfolders same pattern: `Judas/` (active) or `[Judas]/` (archived)

**Files:**
- `hub.md` — Central navigation and index
- `clock.md` — The clock applied to the world
- `characters.md` — Character landscape
- `worldbuilding.md` — World details
- `themes.md` — Thematic seeds
- `scene-seeds.md` — Scene ideas and narrative hooks

**How to use:**
These are thinking tools. Hyperlink between them freely. When working on a scene, pull relevant files into your active workspace. Bracket (archive) ideas you're not using but want to keep for later inspiration.
