# Mindmap

The worldbuilding incubator — loose, hyperlinked, generative.

**What goes here:**
- Character landscapes
- Thematic explorations
- Scene seeds and narrative ideas
- World details and brainstorms
- The Twelve-Hour Clock (applied)

**Structure:**
- `access/` — Themes/characters/ideas you're actively working with
- `shadow/` — The complete worldbuilding archive

**Files:**
- `hub.md` — Central navigation and index
- `clock.md` — The clock applied to the world
- `characters.md` — Character landscape
- `worldbuilding.md` — World details
- `themes.md` — Thematic seeds
- `scene-seeds.md` — Scene ideas and narrative hooks

**How to use:**
These are thinking tools. Hyperlink between them freely. When working on a scene, pull relevant files to `access/`. The loose structure is intentional — let patterns emerge.
