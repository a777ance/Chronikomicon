# Principles

Theory-crafting tools — frameworks, structural logics, thematic lenses.

**What goes here:**
- Cosmological principles
- The Twelve-Hour Clock and variations
- Thematic scaffolding
- Narrative structure notes

Principles are **not** the novel. They are instruments for thinking. Any principle here can be:
- drawn on freely
- held in tension with another
- discarded
- recycled in a new form
- reconfigured mid-process

No principle is binding. The manuscript is the only authority.

**File/Folder Naming:**
- Active principles: `clock-variations.md`, `cosmology.md`
- Archived/exploring: `[experimental-clock].md`, `[abandoned-theory].md`
- Bracket = not currently in use, but keeping for reference

**Managing principles:**
- Work with unbracket versions
- Archive old versions with brackets: `clock.md` → `[clock-v1].md`
- Subfolders work the same way
