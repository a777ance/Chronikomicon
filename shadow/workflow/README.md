# Workflow

Process documentation and project management.

**What goes here:**
- Session goals and timelines
- Draft milestones and versioning
- Layer structure guides
- Narrative outline
- Git and commit discipline notes

**Structure:**
- `access/` — Active session plans and goals
- `shadow/` — Historical process documentation and milestones

**Files:**
- `drafts.md` — Version control and milestone system (historical)
- `goals.md` — 6-month timeline and session protocol
- `layers.md` — Layer structure guide
- `story-outline.md` — Narrative outline
- `HOW-TO.md` — Process guide and instructions

**How to use:**
At session start, move relevant files to `access/` (check your goals, load the outline if needed). Update progress during work. Archive notes to `shadow/` when sessions close.

Keep the fractal clean: working documents in `access/`, completed/archival work in `shadow/`.
