# Workflow

Process documentation — session goals, draft versions, structural guides.

**What goes here:**
- Session planning and goals
- Draft milestones and version tags
- Layer structure documentation
- Story outline and narrative arc

This is your thinking space for *how* you work, separate from *what* you create.

**File/Folder Naming:**
- Active docs: `goals.md`, `story-outline.md`
- Archived versions: `[goals-v1].md`, `[old-outline].md`
- Use brackets for previous versions you want to keep for reference

**Files:**
- `drafts.md` — Version control milestones and tagged releases
- `goals.md` — Session and project goals
- `layers.md` — Architecture and layer structure guide
- `story-outline.md` — Narrative arc and chapter outline

**How to use:**
These are process guides. Update them as your working methods evolve. Archive old versions by adding brackets rather than deleting them.
