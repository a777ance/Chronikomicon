# Reference

Immutable source materials — scripture, art, audio/visual references.

**What goes here:**
- Scripture (KJV Bible text)
- Artwork documentation
- Soundtrack references
- Any material that is "source" rather than "created"

These don't change. They are consulted, not modified.

**File/Folder Naming:**
- Reference materials: `kjv.txt`, `manifest.md`
- No bracket system needed here — reference is static
- If you need to archive an old manifest or doc: `[old-manifest].md`

**Structure:**
- `scripture/` — Biblical text and analysis
- `art/` — Visual references and manifest
- `soundtrack/` — Audio references and manifest

**How to use:**
When writing, pull specific scriptures, art details, or soundtrack notes into your working files. Reference materials stay here permanently (immutable).
