# Reference

Immutable source material — static, never modified, always available.

**What goes here:**
- King James Bible (KJV) — 31,100 verses, complete
- Public domain artwork keyed to scripture
- Music/soundtrack manifest and metadata
- Research materials and citations

**Structure:**
- `access/` — Current reference materials you're actively using
- `shadow/` — The complete archive

**Subfolders:**
- `shadow/scripture/` — KJV text and associated public domain artwork
- `shadow/soundtrack/` — Music paired to chapters and scenes

**Important:**
These are read-only archives. Do not modify. When you need a specific Bible passage or artwork reference, pull the manifest to `access/` but never alter the source.

**For lookup:**
Check `shadow/scripture/kjv.txt` and `shadow/scripture/art/manifest.md` for cross-references.
