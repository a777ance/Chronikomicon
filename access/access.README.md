# Access — Active Working Memory

This folder contains the conscious bubble — files you're actively working with in this session.

**What goes here:**
- Your current chapter if you're writing
- The principles or themes you're referencing today
- Quick reference materials
- Session notes and progress

**File/Folder Naming:**
- No brackets = active/working
- `[name]` = archived/shadowed (use bracket notation if you need to archive something)
- Example: `active-chapter.md` vs `[old-draft].md`

**Managing state:** Rename files/folders by adding or removing brackets to toggle between active and archived.

When you close a session, archive inactive files by adding brackets or moving them to appropriate shadow/ locations.
