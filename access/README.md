# Access — Active Working Memory

This folder contains the conscious bubble — files you're actively working with in this session.

**What goes here:**
- Your current chapter if you're writing
- The principles or themes you're referencing today
- Quick reference materials
- Session notes and progress

**Structure:**
- `access/` — Hyperactive working memory (move files here when you need them *right now*)
- `shadow/` — Recent work that's cooling off but still warm

**Move files in and out deliberately.** Nothing auto-syncs. You're in control.

When you close a session, move inactive files back to the root-level `shadow/` folder.
