## Active concepts

- **Dispensation** — a period governed by its own logic and felt duration. Clock gives position; Dispensation gives character.
- **Sola Scriptura** — scripture is reference. KJV is the text. Never paraphrased. Never read into context (31,100 verses).
- **Layer separation** — `map/` is theory. `manuscript/` is writing. They do not bleed.
- **T-minus zoom** — the session protocol. Perimeters shrink. Gist persists. Lossy is intentional.
