# Dispensations

Each of the 12 clock positions is a **Dispensation** — a period governed by its own internal logic and felt duration.

The clock gives **position**. The Dispensation gives **character**.

Duration is felt, not measured. One Dispensation may span a hundred pages. Another, a single sentence. The clock position does not determine length — the Dispensation's internal logic does.
