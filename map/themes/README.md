## How to add a theme

Create `map/themes/[theme-name].md` with:
- The theme in one sentence
- Which dispensations it inhabits
- Which characters carry it
- Scripture anchors (book chapter:verse — do not read kjv.txt into context)

Then link it here and from any relevant nodes.
