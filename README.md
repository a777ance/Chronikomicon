## The Hard Rules

**Sola Scriptura** — `reference/scripture/kjv.txt` is sealed. Never read it into Claude context (it is 31,100 verses). Never modify it. Quote scripture from memory or search externally.

**Layer separation** — `map/` is theory. `manuscript/chapters/` is writing. They do not bleed into each other.

**T-minus lockout** — Once you compact a zoom level, that perimeter is closed for the session. Do not re-read files from a sealed level.

**Write-mode lockout** — After the final compact, the repo is closed. No more file reads. Everything happens in the journal bubble.

**Minimum** — 220 words per session. Every session.
